# F1 SNAP

A premium Formula 1 Grand Prix archive and race companion focused on the 2025 and 2026 seasons.

F1 SNAP brings together race schedules, results, qualifying, standings, drivers, teams, circuit maps, and manually curated race highlight videos in a single dark editorial interface.

Built as an independent fan-made / educational project.

---

## Features

- 2025 and 2026 Grand Prix archive
- Race Center for individual Grand Prix weekends
- Race results and qualifying data
- Driver standings
- Constructor standings
- Drivers and teams sections
- Circuit Maps archive
- Previous / Next Grand Prix navigation
- Selected-race context across pages
- Responsive desktop, tablet, and mobile layouts
- Manual Formula 1 race highlight links
- Three.js cinematic F1 car experience on the archive page

---

## Tech Stack

- HTML5
- CSS3
- Vanilla JavaScript
- Three.js
- Jolpica F1 API
